# Base64 Helper

A simple Bash script for encoding and decoding Base64 strings.

## Features

* Encode plain text to Base64
* Decode Base64 strings
* Lightweight and easy to use

## Usage

Make the script executable:

```bash id="d1kvv7"
chmod +x base64_helper.sh
```

Encode text:

```bash id="1gykmi"
./base64_helper.sh encode password123
```

Decode text:

```bash id="s1i0yl"
./base64_helper.sh decode cGFzc3dvcmQxMjMK
```
