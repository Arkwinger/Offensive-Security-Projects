# URL Extractor

A simple Bash script that extracts HTTP and HTTPS URLs from a text file.

## Features

* Extracts HTTP and HTTPS URLs
* Removes duplicate entries
* Useful for log analysis, notes, source code reviews, and reconnaissance

## Usage

Make the script executable:

```bash
chmod +x extract_urls.sh
```

Run the script:

```bash
./extract_urls.sh <file>
```

Example:

```bash
./extract_urls.sh notes.txt
```

This script is intended for educational purposes, lab environments, and authorized security assessments only.
