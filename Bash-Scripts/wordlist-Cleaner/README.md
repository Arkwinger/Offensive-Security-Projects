# Wordlist Cleaner

A simple Bash script that removes duplicate entries from a wordlist and generates a cleaned output file.

## Features

* Removes duplicate entries
* Sorts entries alphabetically
* Generates a cleaned wordlist
* Displays original and unique entry counts

## Usage

Make the script executable:

```bash
chmod +x clean_wordlist.sh
```

Run the script:

```bash
./clean_wordlist.sh <wordlist>
```

Example:

```bash
./clean_wordlist.sh words.txt
```

## Output

The cleaned wordlist will be saved as:

```text
cleaned.txt
```
