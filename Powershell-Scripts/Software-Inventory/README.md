# Software Inventory

A PowerShell utility that enumerates installed software on a Windows system and displays application names and versions.

This script can be used for system inventory, asset visibility, lab exercises, and general Windows environment assessment.

## Features

* Enumerates installed applications
* Displays software versions
* Counts total installed applications
* Can be extended to export results to CSV

## Usage

Run the script from PowerShell:

```powershell id="wh9n1k"
.\software_inventory.ps1
```
