# Windows Enum

A PowerShell-based Windows enumeration utility that collects basic host, user, network, and system information.

This script is designed to assist with system discovery, lab exercises, and general Windows environment enumeration.

## Features

* Current user information
* Hostname discovery
* Operating system details
* IPv4 address enumeration
* Local administrator enumeration
* Running process discovery
* Installed software inventory

## Usage

Run the script from PowerShell:

```powershell
.\windows_enum.ps1
```

## Example Output

```text
[+] Current User
DESKTOP\User

[+] Hostname
DESKTOP

[+] Operating System
Windows 11 Pro

[+] IP Addresses
192.168.1.100
```
