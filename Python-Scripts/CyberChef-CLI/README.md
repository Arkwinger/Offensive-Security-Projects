# CyberChef CLI

A terminal-based utility inspired by CyberChef that provides common encoding, decoding, hashing, and data transformation functions from the command line.

## Features

* Base64 Encode / Decode
* URL Encode / Decode
* Hex Encode / Decode
* MD5 Hashing
* SHA1 Hashing
* SHA256 Hashing
* ROT13
* JWT Decoding

## Usage

Run the tool:

```bash
python cyberchef.py
```

Select an operation from the menu and provide input when prompted.

## Example

```text
CyberChef CLI

1. Base64 Encode
2. Base64 Decode

Choice: 1

Input: hello

aGVsbG8=
```
