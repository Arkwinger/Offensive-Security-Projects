# Password Mutator

A Python utility that generates common password variations from a supplied word or phrase.

The goal of this project is to automate the creation of realistic password candidates by applying common capitalization, numbering, and character substitution techniques often encountered during password auditing, testing, and lab environments.

## Features

* Capitalization variations
* Number appending
* Year appending
* Common special character additions
* Basic password mutation rules
* Duplicate removal

## Usage

Run the script:

```bash
python password_mutator.py
```

Enter a base word when prompted:

```text
company
```

Example output:

```text
company
Company
company1
company123
company2025
Company2025
company!
Company!
```
